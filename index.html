Muro de Comentarios del Repositorio

Práctica de Control de Versiones: Deja tu huella en el proyecto

🚀 Instrucciones para dejar tu comentario:

  1. Haz un Fork de este repositorio a tu cuenta de GitHub.
  2. Clona tu repositorio fork en tu computadora (o edítalo desde la web de GitHub).
  3. Abre este archivo index.html y baja hasta la sección de comentarios.
  4. Copia el bloque del "ESTUDIANTE EJEMPLO", pégalo abajo y pon tus datos reales.
  5. Haz un Commit con el mensaje "Añadido comentario de [Tu Nombre]".
  6. Sube tus cambios (Push) y envía un Pull Request (PR) al repositorio del profesor.
